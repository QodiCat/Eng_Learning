我想做一个桌面端的中英翻译程序，可以实时实时全局鼠标划词翻译，按下一个快捷键就可以唤起翻译【AI翻译】，并且可以写出这个词之前是否有被查过（查过几次）每查一个词就可以给这个词增加一次查询次数，翻译的提示词可以自己自定义设置，如果检测到的是句子和词组，暂不支持翻译

可以支持导入词库（如四级或者六级或者雅思或者托福）查询的时候显示是什么类型的词（来源于哪个词库，一个词可能来源于多个词库）

同时有学习功能，每天结束的时候显示当天的学习单词的内容,可以进行复习，复习过的单词就可以点击学习

# 拾词 · WordBridge 开发首版

Windows 桌面划词翻译与学习应用。上方保留原始需求；当前是用户授权的开发首版，不代表 PRD 已批准。

## 运行与配置

开发需要 Node.js 24+、Windows PowerShell。安装会下载 Electron 运行时。

```powershell
npm.cmd ci
npm.cmd run dev
```

首次开发启动自动从 `.env.example` 创建 `.env`。在软件的“翻译设置”填写服务地址、模型和密钥，点击“保存并应用”。也可手动编辑 `.env` 后重新加载配置。不要发送或提交密钥。

地址填服务 API 前缀（通常包含 `/v1`），不含 `/chat/completions`。模型名由你的中转服务提供。服务不要求鉴权时可明确设置 `AI_REQUIRE_KEY=false`。未配置时翻译明确报错，不生成假结果。

## 使用

- 在主窗口切换“学习模式 / 翻译模式”，选择同步到快捷弹窗并在重启后保留。弹窗不显示模式选择或重复原文；翻译模式仅展示译文，不显示保存提示及词库来源。学习模式沿用单词查询、次数和复习；翻译模式支持中英双向的词组、长句和段落，逐次保存原文、译文与时间，不把整句计入学习记录。
- 打开“翻译记录”，点击英文原文或英文译文里的单词，或拖选连续的完整英文词组，再点“加入学习词库”。整体释义查询成功后，会出现在“学习词库”（默认全部词条，可按日期筛选复习）；重复加入会提示，不重复累计。失败或取消不入库。词组不含标点，长度沿用 `MAX_INPUT_LENGTH`。
- 翻译模式默认最多 10000 字符，由 `.env` 的 `MAX_TRANSLATION_INPUT_LENGTH` 调整；仍受服务输出上限限制。混合文本含中文时按中译英处理。小窗 Enter 提交，Shift+Enter 换行。

- 启动后可关闭主窗口，应用会留在系统托盘继续运行。选中中文词语或英文单词，按默认 `Ctrl+Alt+E`，应用读取选区、打开小窗并自动翻译，无需再点翻译。中文译英文（英文译词置于首行），英文查中文；也可在小窗直接输入并按 Enter 查询。
- 默认 `SHORTCUT_MODE=selection` 自动翻译选区。如只需快捷键打开输入框，可在 `.env` 设置 `SHORTCUT_MODE=popup` 并重新加载配置。中文请求将待译词语与指令分开；未返回任何英文的响应显式报错且不计数。
- 小窗显示翻译进度、释义、查询次数和词库来源，支持取消翻译；关闭或按 Esc 隐藏小窗。小窗的“主窗口 / 设置”可返回完整功能。隐藏窗口后已提交的翻译继续执行。
- 托盘图标双击打开主窗口；右键菜单可打开主窗口、快捷翻译或“退出拾词”。只有明确退出才停止后台进程、取消请求并释放快捷键。不包含开机自启。
- 快捷键可在“翻译设置”的“取词快捷键”中修改，点击“保存快捷键”立即应用并保存到本地。无效、占用或保存失败时保留原快捷键。
- 成功翻译后记录次数和当天单词；复习页可查看释义、标记已复习及撤销。
- 词库支持 UTF-8 TXT（每行一个英文单词）或 JSON 数组，如 `["apple","book"]`。同一词可归属多个词库；不内置考试词库。
- 提示词在设置页保存，下次请求生效。服务配置可在设置页保存至本地 .env；已保存密钥不回显。
- 学习记录保存位置显示在设置页；可通过 .env 的 `DATA_DIRECTORY` 指定绝对目录，需重启生效。

## 验证与打包

```powershell
npm.cmd test
npm.cmd run lint
npm.cmd run smoke
npm.cmd run build
```

lint 检查 JS 语法和行数；smoke 使用隐藏窗口与隔离数据，输出 `artifacts/desktop-smoke.png`。检查不使用真实 AI 服务。

测试当前模型的真实 API 连接（会发送一次请求，可能消耗服务额度）：

```powershell
npm.cmd run test:api
npm.cmd run test:api -- hello
```

脚本复用项目根目录 `.env` 的服务配置和现有翻译客户端，进程环境变量优先。默认翻译 `apple`，成功显示译文和耗时，失败输出原因并以非零状态退出；不写入学习记录。软件内保存的自定义翻译提示词不用于此连通性测试。打包版配置在 exe 同级，如要测试该配置，需在项目 `.env` 中配置同一服务。

`UND_ERR_CONNECT_TIMEOUT` 表示连接建立超时，尚未收到 HTTP 响应，不能据此判断密钥或模型无效。其他应用正常时，应对比代理和 DNS 路径。客户端对已识别的 DNS、连接和 TLS 失败显示具体错误代码。

构建产物为 `dist/WordBridge-win32-x64/WordBridge.exe`，需要保留整个目录。包内不含开发机密钥，exe 同级 .env 从空密钥模板生成。当前未签名、无安装器、未发布。

## 当前限制

- 真实服务待本地配置后联调，不能保证所有中转服务兼容。
- 取词先尝试选区读取，再复制并恢复剪贴板；权限差异、自定义控件和保护内容可能导致失败，所有应用兼容性尚未验证。
- 学习模式英文限单词；中文词语/短语支持，整句仅靠标点和换行初步限制。翻译模式支持整句与词组。
- 当前按本机日期记录、主动打开复习列表；自动日终展示/提醒尚未实现。
- 先提供 Windows x64 包；其他架构和不同系统版本需后续验证。暂定规则见 [开发范围](.product/phase-1/development-scope.md)。

### 在软件内配置服务

在「翻译设置」填写服务地址、模型名称和 API 密钥，点击「保存并应用」，无需手动编辑文件或重启。配置保存在设置页显示的本机 `.env` 路径中，重启自动读取。密钥以明文保存在本机，不回显；留空保留原密钥，需要删除时勾选「清除已保存的密钥」。无需鉴权的服务可取消「服务需要 API 密钥」。保存不会测试真实服务连接。



### 请求鉴权与网络

桌面翻译使用 Electron 的网络栈，支持系统代理。`npm run test:api` 使用 Node 网络栈，连通性结果可能与桌面不同。

`.env` 的 `AI_AUTH_SCHEME` 默认 `bearer`，自动添加 `Bearer ` 前缀；服务要求原样 Authorization 时设为 `raw`，重新加载配置。密钥仍通过翻译设置保存，不应写入源码。个人联调参考 `test.py` 不纳入 Git 或应用包。

构建可选配置：`ELECTRON_ZIP_DIRECTORY` 指向包含当前 Electron 版本 Windows x64 ZIP 的目录，可写入本机 `.env` 或由进程环境传入。未设置时沿用打包器资源获取逻辑；资源下载失败时会显式报错。本轮用已存在的匹配版本缓存完成构建。


官方词库管理外部导入的四级、六级、雅思、托福等词表，不内置考试词表。

已下载可导入的四级、六级、雅思、托福社区词表，见 [本地词表与导入说明](resources/vocabulary/README.md)。在“官方词库”填写名称后选择对应 TXT 即可；来源、许可、固定版本及过滤明细随文件保留。

学习词库点击“开始学习”，按当前日期筛选结果依次显示卡片。查看释义后点击“下一词”或“完成”，该词学习次数增加一次并保存；未完成即退出不计数。学习次数与查询次数、复习标记独立，旧词条从 0 次开始。

卡片展开释义后可点击“生成助记”，通过现有 AI 服务生成联想、适用的词根词缀、谐音、场景例句和回忆自测，保存后下次卡片直接展示，可重新生成或取消请求。谐音仅助记，不是标准发音；不适用的方法应说明而非编造。生成助记不增加查询或学习次数，失败保留已有助记并显示错误。

学习词库显示总词数、已学习、待学习：统计整个词库的去重词条（词组按一个条目计），学习次数大于 0 即为已学习，其余为待学习。日期筛选不改变总体统计。
